# dbus-pump

[English](README.md) · [Русский](README.ru.md) · [Deutsch](README.de.md) · [Nederlands](README.nl.md)

**Версия:** явные единицы, диагностический второй датчик, локализация и строгая
проверка команд ниже относятся к **ещё не выпущенной версии разработки**.
Используйте эту ревизию исходников или включающий её релиз; старые версии
могут вести себя иначе. См. [CHANGELOG.md](CHANGELOG.md).

Мост между Home Assistant и **Victron Venus OS** для бака, насоса и клапана.
Работает на Cerbo GX, читает сущности HA и публикует нативные сервисы D-Bus.
Показания доступны интерфейсу GX и потребителям Cerbo MQTT. Автоматика клапана
включается отдельно; у насоса предусмотрено ручное управление.

![Показания HA проходят преобразование единиц на Cerbo и публикуются в D-Bus и MQTT; команды возвращаются в HA.](docs/assets/architecture.svg)

## Установка

Нужны системный Python **3.12.x**, `requests`, D-Bus и GI/GLib от установленной
Venus OS. Не заменяйте системный Python. Версия для разработки — 3.12.13.

1. Разместите пакет в `/data/dbus-pump`.
2. Скопируйте `local_config.example.py` в `local_config.py` и укажите URL, токен,
   сущности HA, единицы измерения и геометрию вашего бака. Не публикуйте токен.
3. Оставьте `ENABLE_CONTROL = False` до проверки показаний и владельца управления.
4. Проверьте зависимости и установите пакет:

```sh
python3 --version
python3 -c "import requests, dbus; from gi.repository import GLib"
/data/dbus-pump/setup install
svstat /service/dbus-pump-ha /service/dbus-pump-ha/log
readlink /service/dbus-pump-ha
tail -n 40 /var/log/dbus-pump-ha/current
```

Правильная ссылка: `/service/dbus-pump-ha` →
`/data/dbus-pump/service/dbus-pump`. Каталог `/service/dbus-pump` относится к
штатному сервису прошивки: не удаляйте его и его маркер `down`.

Для установки с компьютера с настроенным SSH используется `./deploy.sh Cerbo`.
Он **заменяет конфигурацию на устройстве**, если в локальном репозитории есть
`local_config.py`. Обычное обновление пакета сохраняет конфигурацию устройства.
После установки сравните свежие значения D-Bus с HA; одного статуса `up` мало.
Подробности: [установка и откат — EN](docs/operator/installation.md).

## Конфигурация и исправление единиц

Это пример для настроенной установки; проверьте сущности и размеры своего бака:

```python
HA_URL = "http://homeassistant.local:8123"
HA_TOKEN = "replace_with_private_long_lived_token"
HA_WATER_LEVEL_ENTITY = "sensor.water_level_2_water_level"
HA_WATER_LEVEL_UNIT = "cm"
HA_PUMP_SWITCH_ENTITY = "switch.pump_power_enable"
HA_VALVE_SWITCH_ENTITY = "switch.shutoff_valve"
TANK_CAPACITY_LITERS = 387.0
TANK_WATER_CM_ENTITY = "sensor.water_cm"  # только диагностика
TANK_OFFSET_CM = 18.0
TANK_RADIUS_CM = 35.56
LANGUAGE = "ru"
ENABLE_CONTROL = False
```

**93 см — не 93%.** Единицу первичного датчика задаёт `HA_WATER_LEVEL_UNIT`:
`"cm"` для высоты воды, `"%"` для уже рассчитанных процентов. Значение по
умолчанию — `"%"`. Непустая единица в HA должна совпадать с конфигурацией.
Для `cm` нужны положительные конечные ёмкость и радиус, а также конечное
смещение; неверная геометрия не допускает запуск.

Для вертикального цилиндра объём в литрах равен
`max(0, см − смещение) × π × радиус² / 1000`, с ограничением ёмкостью бака.
При указанных размерах 93 см дают около **297,94 л и 76,99%**.
`/Level` всегда выражен в процентах, `/Capacity` и `/Remaining` — в **м³**:
`0.298 м³` означает около 298 л после округления.

В режиме `%` остаток рассчитывается из ёмкости и того же процента.
`TANK_WATER_CM_ENTITY` теперь служит только диагностике и не переопределяет
объём другим датчиком. Это изменение прежнего поведения. Формула цилиндра
не подходит горизонтальным или бакам сложной формы; датчик расстояния до
поверхности сначала нужно преобразовать в высоту воды.

![Расчётная кривая для бака 387 л: смещение 18 см, радиус 35,56 см; 93 см соответствуют примерно 77%.](docs/assets/calibration.svg)

## Управление и безопасность

В настроенной установке насосом и клапаном управляют активные автоматизации HA.
Оставьте `ENABLE_CONTROL=False`, пока оператор намеренно не передаст управление.
Между разными программами нет блокировки или согласования команд.

Этот флаг отключает **только автоматические решения**. Ручные записи `/Mode` и
закрытие клапана при штатном завершении остаются активными. Перезапуск может
закрыть клапан, поэтому не используйте его как безобидную проверку здоровья.

В AUTO клапан открывается при ≤30% и закрывается при ≥85%; между обычными
переключениями — минимум 60 с. Просроченные данные вызывают запрос закрытия
через 120 с. После такого закрытия возврат показаний в середину диапазона
сам по себе не открывает клапан. `/Mode`: `0` AUTO, `1` ВКЛ, `2` ВЫКЛ.
Ручной режим ВКЛ обходит автоматическую защиту по устаревшим показаниям.
Насос не имеет автоматического алгоритма по уровню.

![Гистерезис клапана: открытие до 30%, закрытие от 85%, между порогами сохраняется предыдущее решение.](docs/assets/hysteresis.svg)

Принятие команды HA не доказывает физическое закрытие. Потеря питания Cerbo,
недоступность HA или неисправность оборудования могут помешать закрытию;
нужна подходящая аппаратная защита. [Модель управления — EN](docs/operator/control.md).

## Языки и интерфейсы

`LANGUAGE` поддерживает `en`, `ru`, `de`, `nl`; варианты локали нормализуются,
неизвестный язык заменяется английским. Переводятся названия устройств и текст
состояний/режимов D-Bus. Логи остаются английскими. Имена сущностей HA, числовые
значения, пути и идентификаторы не переводятся:

- Бак: `com.victronenergy.tank.ha_tank21`.
- Насос: `com.victronenergy.pump.startstop1`.
- Клапан: `com.victronenergy.pump.startstop2`.
- MQTT: `N/<portal>/tank/21/Level`, `N/<portal>/pump/1/State`,
  `N/<portal>/pump/2/State`.

[Как дополнить перевод — EN](docs/operator/localization.md).
Подробные руководства, wiki и подписи внутри SVG пока на английском.

## Диагностика и разработка

- Неверные проценты: проверьте единицы HA и `HA_WATER_LEVEL_UNIT`, ёмкость,
  радиус и смещение. Не компенсируйте ошибку порогами автоматики.
- Показания недоступны: проверьте HA, токен и существование сущностей. Ошибочные
  данные не продлевают срок свежести; неизвестный объём не считается пустым баком.
- Сервис не запускается: проверяйте `dbus-pump-ha`, зависимости и журнал.
- Клапан действует неожиданно: проверьте `/Mode` и все автоматизации HA.
